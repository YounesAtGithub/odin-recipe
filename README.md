# The Odin Project - First Assignment

This repository contains my work for the **first assignment** of [The Odin Project](https://www.theodinproject.com/).  
The goal of this exercise was to practice basic **HTML structure and elements**.

## 🧩 Project Description

In this project, I created a simple HTML page that includes:

- **Links** (`<a>` tags) to different web pages  
- **Ordered lists** (`<ol>`) and **unordered lists** (`<ul>`)  
- **Images** (`<img>`) to display visual content  

This assignment helped me understand how to structure a webpage, organize content, and include media and navigation links.

## 🛠️ Skills Practiced

- Writing semantic HTML  
- Using links and lists properly  
- Embedding images with relative and absolute paths  
- Basic HTML file structure (`<!DOCTYPE html>`, `<head>`, `<body>`)

- `index.html` — Main HTML file containing the assignment implementation
